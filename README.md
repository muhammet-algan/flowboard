# 🚀 FlowBoard - Premium SaaS Dashboard

![Dashboard Preview](docs/images/dashboard.png)

FlowBoard is a state-of-the-art, premium productivity and team management dashboard built with modern web technologies. It combines high-end aesthetics with powerful functionality to help individuals and teams achieve "flow" in their daily work.

## ✨ Key Features

-   **📊 Dynamic Dashboard:** Comprehensive overview of your productivity with interactive charts and real-time analytics.
-   **📋 Advanced Kanban Board:** Manage tasks with ease using a drag-and-drop interface, priority levels, and member assignments.
-   **⚡ Focus Mode:** A dedicated space for deep work featuring a Pomodoro timer and distraction-free environment.
-   **📝 Integrated Notes:** Quickly capture ideas and maintain your documentation without leaving the platform.
-   **👥 Team Collaboration:** Manage team members, track assignments, and optimize collective performance.
-   **🎨 Premium Design:** Sleek dark mode, glassmorphism effects, and smooth animations powered by Framer Motion.

## 🛠️ Tech Stack

-   **Frontend:** [React.js](https://reactjs.org/) (Vite)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
-   **State Management:** [Zustand](https://github.com/pmndrs/zustand)
-   **Animations:** [Framer Motion](https://www.framer.com/motion/)
-   **Charts:** [Recharts](https://recharts.org/)
-   **Icons:** [Lucide React](https://lucide.dev/)
-   **Drag & Drop:** [@dnd-kit](https://dndkit.com/)

## 🚀 Getting Started

### Prerequisites

-   Node.js (v18 or higher)
-   npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/flowboard.git
    cd flowboard
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Open your browser:**
    Navigate to `http://localhost:5173` to see the application in action.
